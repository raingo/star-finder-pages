## Overview

Star Finder is an interactive, offline-capable night sky planetarium and stargazing Progressive Web App (PWA).

### ✨ Features
- **Accurate Celestial Engine**: Real-time positions for 9,000+ stars, 88 constellations, 8 planets, the Sun, and high-precision Moon phase illumination fraction.
- **Classic Astrophotography Milky Way**: Realistic multi-scale star clouds, Great Rift dust lanes, Grand Galactic Bulge, and adaptive scotopic night mode palettes.
- **Sensors & AR Mode**: Gyroscope, compass, and camera background projection with automatic calibration and lighting meter.
- **Interactive Search & Fact Sheet**: Filterable search with "Visible in Camera" dropdown sorted by apparent magnitude.
- **Bilingual Interface**: Full English and Chinese (Simplified) support with astronomical terminology.
- **100% Offline Capability**: Built-in Service Worker precaches all core scripts, styles, textures, and datasets.
